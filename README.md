# OAI 5G Smart Agriculture Baseline

This repository contains the experiment configurations, traffic-generation scripts, and results supporting the paper *“Baseline Performance of OpenAirInterface 5G NR Without Service Differentiation Under Heterogeneous Smart Agriculture Traffic.”*

The study evaluates a standalone OpenAirInterface (OAI) 5G testbed using synthetic eMBB, mMTC, and URLLC uplink traffic in isolated, pairwise, and full-coexistence scenarios, without per-service slices or scheduler modifications.

The experiments establish a reproducible baseline for future resource-allocation and optimisation studies. Measurements use a single-host RF-simulator deployment and represent a controlled software baseline.
